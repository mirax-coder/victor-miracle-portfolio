VICTOR MIRACLE — PORTFOLIO WEBSITE

Files:
- index.html: portfolio website
- styles.css: responsive styling and animations
- script.js: mobile navigation, case-study modal, contact form, scroll effects
- resume.html: editable resume page with Print / Save as PDF
- assets/victor-miracle.jpg: profile photo used in the About section

HOW TO USE
1. Keep all files in the same folder.
2. Open index.html in a browser, or upload the folder contents to your hosting provider.
3. Your profile photo is included at assets/victor-miracle.jpg; replace that file to use a different photo.
4. Update social links in index.html to your personal profiles.
5. The contact section and resume include miraclev188@gmail.com.
6. Update project case study content in script.js as your portfolio grows.
7. Open Resume from the navigation, then use Print / Save as PDF to export the resume.
